## How to save exports

Use the native export/download function for the relevant ChatGPT or Codex conversation if available in the account/app. Preserve each source export as its own file in this directory, keeping its original format and filename where possible. If a platform provides only an account-wide archive, extract only the relevant project conversation into a clearly identified separate file and keep unrelated conversations out of this repository. Do not copy the summarized `ai-work-log.md` and label it an export.

Before adding an export to Git, inspect it for API keys, credentials, `.env` contents, personal data, or unrelated sensitive material. Do not commit a raw export containing secrets. Request or prepare an appropriately sanitized export without altering it in a way that misrepresents it as a verbatim original; document any omitted/sanitized portions. Never include secrets in this repository.
